# Assignment 1: Data Preprocessing

This repository contains a Jupyter Notebook for Machine Learning Assignment 1, Data Preprocessing.

## Dataset

I Use the Kaggle dataset: **House Prices: Advanced Regression Techniques**.

Download these files from Kaggle:

- `train.csv`
- `test.csv`

Create a folder named `data` and place both csv files inside it:

Assignment01/
│-- ML_Assignment1_Data_Preprocessing.ipynb
│-- README.md
│-- data/
    │-- train.csv
    │-- test.csv

## How to Run

Install the required packages in python:
numpy
pandas
matplotlib
seaborn
scikit-learn

Then open the notebook and run all cells from top to bottom.
